# EDD Paddle Billing Gateway

Free Paddle Billing v2 gateway for Easy Digital Downloads. Accept one-time payments via Paddle's off-site redirect checkout, with sandbox/live modes, single-price product sync, and signed webhooks.

## Requirements

- WordPress 6.0+
- Easy Digital Downloads 3.0+
- PHP 7.4+
- A Paddle account (sandbox or live) with API key, client token, and webhook secret

## Installation

Upload the plugin zip via **Plugins → Add New → Upload Plugin** in WordPress, then activate. Configure under **Downloads → Settings → Payment Gateways → Paddle**.
